# Bash Security Scripts

A collection of Bash scripts developed for practical cybersecurity tasks, including vulnerability information retrieval, network discovery, and authentication log analysis.

## Projects

| Project | Description |
|---|---|
| CVE Lookup | Retrieves CVE details and severity information from the NIST NVD API. |
| Host Discovery | Discovers live hosts within a given network using Nmap. |
| Authentication Log Analyzer | Analyzes Linux authentication logs, identifies frequent source IPs, performs GeoIP lookups, and adds UFW deny rules. |

## Repository Structure
Each directory contains the standalone script along with its own `README.md` covering usage examples, design decisions, and architectural trade-offs.
